# Intelligent Text Analyzer

## Project Overview

Intelligent Text Analyzer is a Python-based project designed to analyze text and extract useful information from written content. It provides an interactive way to explore text characteristics, word frequency, and similarities between texts.

## Features

- Count words, characters, and sentences.
- Analyze word frequency and identify the most frequently used words.
- Identify unique and repeated words.
- Find the longest word in a text.
- Search for specific keywords.
- Compare two texts and measure their word similarity.
- Interact with the program through a menu-driven interface.
- Save text analysis reports to a file.

## Technologies Used

- Python 3
- Strings and string manipulation
- Lists, sets, and dictionaries
- Loops and conditional statements
- Functions
- File handling

## Purpose

The purpose of this project is to practice Python programming and demonstrate how programming techniques can be used to analyze text, organize information, and extract meaningful insights from written content.

## Project Files

- `Intelligent_Text_Analyzer.py` — Python source code.
- `Intelligent_Text_Analyzer.ipynb` — Jupyter Notebook version.

## How to Run

Run the Python file in a Python 3 environment.

Alternatively, open the Jupyter Notebook in a compatible environment and execute the cells in order.
